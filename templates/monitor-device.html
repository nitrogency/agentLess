Device Setup

Setup Instructions

{{if eq .Device.OSType "windows"}}

To set up this Windows device for monitoring, follow these steps:

  1. Get your SSH public key from the IDS server 
    sudo cat {{.Device.SSHKeyPath}}.pub

    Copy the entire output

  2. Transfer the enrollment script to Windows

    You can either copy the "enlist-windows.ps1" script from the github repo or from the monitoring server. If possible copy over to your setup user's Temp folder.

    Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nitrogency/agentLess/main/scripts/windows/enlist-windows.ps1" -OutFile "C:\Users\<YOUR-WINDOWS-USER>\AppData\Local\Temp\enlist-windows.ps1"
  3. Run the enrollment script on Windows (as Administrator) 
    cd C:\Users\<YOUR-WINDOWS-USER>\AppData\Local\Temp
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\enlist-windows.ps1 -ServerIP <IDS-SERVER-IP> -MonitoringUser {{.Device.SSHUser}}

    Replace <IDS-SERVER-IP> with this server's IP, then paste the SSH public key from step 1 when prompted

  4. Start the setup-monitoring.sh script on the server 
    sudo /opt/agentless/scripts/setup-monitoring.sh
{{else}}

To set up this Linux device for monitoring, you need to run the following script with these parameters:

sudo /opt/agentless/scripts/linux/enroll-device.sh -u {{.Device.SSHUser}} -g {{.Device.SSHGroup}} {{if .Device.SetupUser}}-l {{.Device.SetupUser}}{{end}} {{if ne .Device.SSHPort 22}}-p {{.Device.SSHPort}}{{end}} -k {{.Device.SSHKeyPath}} {{.Device.IPAddress}}
