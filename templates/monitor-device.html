Device Setup

Setup Instructions

{{if eq .Device.OSType "windows"}}

To set up this Windows device for monitoring, follow these steps:

  1. Get your SSH public key from the IDS server 
    cat {{.Device.SSHKeyPath}}.pub

    Copy the entire output

  2. Transfer the enrollment script to Windows

    You can either copy the "enlist-windows.ps1" script from the github repo or from the monitoring server. If possible copy over to your setup user's Temp folder.

    Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nitrogency/agentLess/main/scripts/windows/enlist-windows.ps1" -OutFile "C:\Users\{{.Device.SetupUser}}\AppData\Local\Temp\enlist-windows.ps1"
  3. Run the enrollment script on Windows (as Administrator) 
    cd C:\Users\{{.Device.SetupUser}}\AppData\Local\Temp
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\enlist-windows.ps1 -ServerIP <IDS-SERVER-IP> -MonitoringUser {{.Device.SSHUser}}

    Replace <IDS-SERVER-IP> with this server's IP, then paste the SSH public key from step 1 when prompted

{{else}}

To set up this Linux device for monitoring, follow these steps:

  1. Copy the server's public key to the client device: 
    ssh-copy-id -i {{.Device.SSHKeyPath}}.pub {{if .Device.SetupUser}}{{.Device.SetupUser}}{{else}}root{{end}}@{{.Device.IPAddress}}

    If you're using a custom SSH port, add -p PORT_NUMBER to the command.

  2. Run the enrollment script from your terminal: 
    ./scripts/linux/enlist.sh {{if not .Device.RandomUser}}-u {{.Device.SSHUser}} -g {{.Device.SSHGroup}}{{else}}-r{{end}} {{if .Device.SetupUser}}-l {{.Device.SetupUser}}{{end}} {{if ne .Device.SSHPort 22}}-p {{.Device.SSHPort}}{{end}} {{.Device.IPAddress}}
{{end}}

Important!

After enrolling the device, run the monitoring setup script to start automatic monitoring (may require sudo):

./scripts/setup-monitoring.sh

This will create a systemd service for each device and start log collection automatically.
